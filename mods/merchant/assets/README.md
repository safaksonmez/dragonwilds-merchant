# Source assets

This folder contains `native-item-paths.json`, a build-248854 roster of 572 verified ItemData asset references used by `scripts/build-native-content.py`. These are paths only, not extracted game files or player discovery records. The source roster itself is not automatically included in the installation ZIP; generated runtime definitions are in `src/`.

Original mod icons, Nexus screenshots, and owned visual source files may also be stored here later.

If cooked UI, NPC, or Blueprint content is needed later, first verify the engine version, tooling, and package layout. Do not store extracted game content here.
