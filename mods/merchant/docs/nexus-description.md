# Nexus listing draft — unpublished

**Dragonwilds Merchant** adds a fixed, map-marked Coin Merchant in Bramblemead Valley and integrates buying/selling discovered content with a new Coin item.

**0.3.0-dev.3 is an experimental development build.** The latest dynamic catalog fix and the native economy, animation, and decoration regressions are unverified. Remote co-op client catalog synchronization is not implemented. Do not describe this as a verified end-user release.

Dependencies: compatible Dragonwilds UE4SS and RuneSchema 0.8.0.3. Distribution layout: RuneSchema JSON add-on with a nested Lua companion. Loader binaries and free-Coin tools are excluded.

Before publishing to Nexus: complete game and clean Vortex installation/update/removal tests, record exact compatibility, capture real gameplay screenshots, and settle licensing/credits. Installation and removal instructions are in the merchant README. No Nexus upload has been made.
